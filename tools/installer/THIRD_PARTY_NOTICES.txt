Rayman 3 HD Recompiled - third-party notices
============================================

bin\ contains machine code translated from the Xbox 360 game and a runtime with the public Xbox 360 XEX2 retail
key compiled in (it decrypts the owner's Default.xex on this computer at every start); data\ (created on this
computer) contains the game's own files extracted from the owner's package.
