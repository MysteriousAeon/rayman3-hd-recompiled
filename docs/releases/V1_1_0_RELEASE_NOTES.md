# Rayman 3 HD Recompiled v1.1.0

This update adds mouse controls, an in-game Settings panel, DualSense controller-speaker effects, and several HD+ visual fixes for issues inherited from the Xbox 360 release.

## Mouse Controls

- Added optional mouse camera controls with adjustable sensitivity.
- Added optional mouse button support for gameplay actions, including attacking.
- Mouse camera control also works in Look Mode.
- Mouse controls can be configured independently under Settings → Mouse. Both Mouse Camera and Mouse Buttons are disabled by default.

## In-Game Settings

- Added an in-game PC Settings panel, accessible with F4.
- Common settings can now be changed without closing the game. Options that require a restart are identified in the panel.

## HD+ Improvements

HD+ now includes three additional visual corrections:

- **Lighting:** Removed the unnatural pink tint affecting parts of Hoodlum Headquarters and the Tower of the Leptys.
- **Sky colors:** Restored the blue sky in Clearleaf Forest and the blue cloud backgrounds in the Bog of Murk.
- **Fist charge effect:** Restored the changing colors of Rayman's charge trail, which now becomes warmer and more visible as the punch charges.

These corrections are enabled by default in HD+. Vanilla retains the original Xbox 360 HD appearance, while Custom allows individual corrections to be enabled or disabled.

## DualSense Improvements

- Added optional sounds through the DualSense controller's built-in speaker, including power-up activation, pickup, and expiration effects.
- Added a separate volume control under Settings → Advanced.
- Controller-speaker effects require a USB connection and are disabled by default.

## Settings & Other Improvements

- Moved visual corrections to a dedicated Corrections page, making them easier to find and configure.
- Gameplay Subtitles now appears in the Display section of the Settings page.
- Clarified how the Auto rendering resolution option works.
- Updated the English and Turkish Settings interfaces.

## Updating from v1.0.3

Close the game and Settings before updating.

**Installer:** Run the new setup and select your existing installation folder. Existing saves, mods, settings, and preferences are preserved.

**Portable ZIP:** Extract the new package to a writable folder. Follow the included `PORTABLE.txt` instructions when migrating data from an earlier portable copy.

HD+ automatically enables the new visual corrections. Existing Custom preferences are preserved, and corrections without a saved preference follow the Custom profile's base.

Backing up your settings and profiles before updating is strongly recommended.

The installer and portable edition require your own supported Xbox 360 Rayman 3 HD package (title ID `5841123F`, without a title update). No game files are included.

## Additional Notes

- The game continues to run at 60 FPS. Higher frame rates were evaluated but are not supported because they affect gameplay behavior.
- The optional Turkish translation package remains v1.0.1, with unchanged contents.
- Some visual issues inherited from the Xbox 360 HD release remain. A rare audio-initialization crash has also been observed during testing.
- This is a Windows release. Linux and Steam Deck compatibility have not been officially verified.
